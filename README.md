# STAT 248 Final Project

This repository contains my reproducible analysis for the STAT 248 final project.

## Files

- `FinalProject_updated.ipynb`: main Jupyter notebook
- `Berk.comb.long.csv`: raw Berkeley Earth temperature anomaly data
- `figures/`: generated figures used in the analysis and presentation

## How to Run

Open `FinalProject_updated.ipynb` in Jupyter Notebook or JupyterLab and run all cells from top to bottom. The notebook reads the raw CSV from the project folder and reproduces the analysis, figures, diagnostics, and model results.
