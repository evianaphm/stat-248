# STAT 248 Final Project

This repository contains my reproducible analysis, presentation materials, and project proposal for the STAT 248 final project.

## Files

- `STAT248_FinalProject.ipynb`: main reproducible Jupyter notebook
- `STAT248_FinalProject.html`: rendered HTML version of the notebook
- `Berk.comb.long.csv`: raw Berkeley Earth temperature anomaly data
- `figures/`: generated figures used in the analysis and presentation
- `STAT248_FinalProjectppt.pdf`: final presentation slides
- `STAT248_ProjectProposal.pdf`: original project proposal

## How to Run

Open `STAT248_FinalProject.ipynb` in Jupyter Notebook or JupyterLab and run all cells from top to bottom. The notebook reads `Berk.comb.long.csv` from the project folder and reproduces the preprocessing, analysis, figures, diagnostics, model results, and final summaries.

The notebook assumes it is being run from the repository root, with `Berk.comb.long.csv` and the `figures/` folder in the same directory.
